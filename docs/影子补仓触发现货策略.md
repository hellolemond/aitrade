# 影子补仓触发现货策略

> 独立策略方案，与任何现有项目无关。本文只定义规则，不含实现。

## 1. 核心思路

策略分两层：

- **模拟层（影子仓位）**：不下真实单，多空交替逆势补仓，回到均价就平仓。模拟单在均价平仓，盈亏约等于 0，它只负责判断"跌深了"和"反弹回来了"。
- **真实层（现货）**：模拟多单累计下跌达到 N% 后才开始买入现货，之后按等额、等距继续买。模拟单平仓或模拟空单加仓时，分批卖出。

真实仓位比模拟仓位进场更晚、买得更低，所以模拟单回到均价时，真实仓位已经有浮盈。这就是策略的利润来源。

## 2. 参数

| 参数 | 含义 | 建议默认值 |
|---|---|---|
| `step` | 模拟加仓间距 | 0.5% |
| `N` | 真实介入阈值（模拟多单累计跌幅） | 5% |
| `real_step` | 真实加仓间距 | 0.5%（与 step 相同） |
| `real_amount` | 真实每档买入金额（USDT） | 10U |
| `real_cap` | 真实总投入上限（USDT） | 例如 200U |
| `first_sell_ratio` | 模拟多单平仓时首次卖出的比例 | 30% |
| `sell_parts` | 剩余持仓分成几份，在模拟空单加仓时逐档卖出 | 5 |
| `min_profit` | 卖出价相对真实持仓均价的最低利润要求 | 0.3%（覆盖双边手续费） |
| `first_side` | 首个模拟单的方向 | 多 |

## 3. 模拟层规则

### 3.1 档位价格

档位价格以本轮模拟单的首单价格 `P0` 为基准，**按线性计算**（第 10 档正好是 -5%）：

- 模拟多单第 k 次加仓价：`P0 × (1 − k × step)`
- 模拟空单第 k 次加仓价：`P0 × (1 + k × step)`

首单记作 k=0。每档数量相同。

### 3.2 均价与平仓

已经成交 k+1 档（含首单）时，模拟均价为：

- 多单：`P0 × (1 − k × step / 2)`
- 空单：`P0 × (1 + k × step / 2)`

价格回到均价时平仓：多单要求价格 ≥ 均价，空单要求价格 ≤ 均价。只有首单、还没加仓时，均价就是首单价，价格一回到首单价就平仓。为避免来回抖动反复触发，只有至少加过一档后才允许平仓（`k ≥ 1`）。

### 3.3 方向交替

模拟单平仓后，立即以平仓价为新的 `P0`，开反方向的模拟单：多单平仓后开空单，空单平仓后开多单。

### 3.4 价格来源

- 实盘时使用最新成交价，并在每个价格更新时检查。
- 回测时使用 1 分钟 K 线。同一根 K 线里，加仓和平仓可能都会触发，但先后顺序未知，所以一律按"先不利、后有利"的保守顺序处理：多单先按最低价检查加仓，再按最高价检查平仓。
- 价格一次跳过多个档位时，按跳过的档数逐档补记（模拟层与真实层都按档位价格记账，不按跳空后的成交价记账）。

## 4. 真实层规则（只做现货多头）

### 4.1 开始买入

当前模拟单为多单，且累计跌幅 `k × step ≥ N` 时，真实层开始介入。按默认值，就是模拟多单加到第 10 档、价格跌到 `P0 × 0.95` 时，买入第一笔现货。

### 4.2 继续买入

从第一笔真实买入价 `R0` 开始，每再跌 `real_step` 买入一笔 `real_amount`：买入价依次为 `R0 × (1 − j × real_step)`。

- 已投入金额加上本笔会超过 `real_cap` 时，停止买入，只持有。
- 模拟层不受上限影响，继续加档、计算均价。

### 4.3 卖出

1. **模拟多单平仓时**：卖出真实持仓的 `first_sell_ratio`。
2. **随后的模拟空单每加一档**：卖出一份。份额 = 首次卖出后剩余数量 ÷ `sell_parts`。
3. 卖到最后一份，或剩余持仓低于交易所最小下单金额时，一次全部卖出，本轮真实仓位结束。

**利润保护**：每次卖出前检查卖出价是否 ≥ 真实持仓均价 × (1 + `min_profit`)。不满足时跳过这一次卖出，持仓保留到下一个卖出时机。

### 4.4 没卖完价格又下跌

模拟空单在价格回落到它的均价时平仓，随后开新的模拟多单。这时如果真实层还有剩余持仓：

- 暂停分批卖出。
- 新的模拟多单累计跌幅再次达到 N 时，恢复买入。新的买入并入原有持仓，重新计算持仓均价，上限 `real_cap` 按合并后的总投入计算。
- 下一次模拟多单平仓时，按第 4.3 节重新开始卖出：先卖出当前持仓的 `first_sell_ratio`，再重新计算每份数量。

### 4.5 模拟空单上涨达到 N%

现货不能做空，所以真实层不开空单。模拟空单加仓只用于第 4.3 节的分批卖出。

## 5. 示例

默认参数，`P0 = 100`，模拟多单开局：

| 阶段 | 价格 | 模拟层 | 真实层 |
|---|---|---|---|
| 开仓 | 100 | 模拟多单首单 | 无 |
| 下跌 | 99.5 … 95.5 | 每 0.5% 加一档 | 无 |
| 触发 | 95 | 第 10 档，累计 -5% | 买入 10U |
| 继续下跌 | 94.5 … 92 | 共 17 档，均价 96 | 每档买 10U，共 7 笔 70U，均价约 93.49，持有约 0.7487 个 |
| 反弹 | 96 | 回到均价，模拟多单平仓，开模拟空单（P0=96） | 市值约 71.88U，浮盈约 +2.7%（未扣手续费）；卖出 30% |
| 继续上涨 | 96.48 … 98.40 | 模拟空单每 0.5% 加一档 | 每档卖出剩余的 1/5，到 98.40 全部卖完 |

这里的 30% 和 1/5 都是数量比例，不是金额比例。

## 6. 风险与边界

1. **单边下跌**：如果一路下跌、长期不反弹，模拟多单就一直不平仓，真实仓位会长期被套。`real_cap` 只限制投入多少，不限制亏损。建议另设"真实首笔买入后再跌 X%（例如 30%）就告警并人工处理"，默认不自动止损卖出。
2. **触及上限后可能亏损卖出**：真实买入在 `real_cap` 处停止后，模拟层继续加档，模拟均价会继续下移。大约再跌 N% 以后，模拟均价就会低于真实持仓均价，这时按模拟均价卖出就是亏损。第 4.3 节的利润保护就是用来防止这种情况的。
3. **手续费**：现货单边约 0.1%（用 BNB 抵扣约 0.075%）。`min_profit` 至少要覆盖买卖双边手续费。
4. **最小下单金额**：现货通常有最小名义金额限制（例如 5U）。份额太小时，合并到下一份或一次卖完。
5. **币种风险**：下架、长期阴跌的小币不适用。建议只用于流动性好的主流币，并配置币种白名单。
6. **资金占用**：多个币种同时运行时，`real_cap` 要按全部币种的合计投入来规划。

## 7. 状态与伪代码

```
状态:
  sim: {side, P0, k}              # 模拟方向、首单价、已加档数
  real: {qty, cost, R0, j, sell_unit, selling}

on_price(p):
  # 1. 模拟层加仓（逐档补记）
  while sim 的下一档已经被 p 触及:
    sim.k += 1
    if sim.side == 多 and sim.k*step >= N: real_buy_level()
    if sim.side == 空 and real.selling:    real_sell(real.sell_unit)

  # 2. 真实层继续买入（已介入后按 real_step 等距买入）
  if sim.side == 多 and 已介入 and p 触及 R0*(1-(j+1)*real_step): real_buy_level()

  # 3. 模拟层平仓与反手
  if sim.k >= 1 and p 回到模拟均价:
    if sim.side == 多 and real.qty > 0:
      real_sell(real.qty * first_sell_ratio)
      real.sell_unit = real.qty / sell_parts
      real.selling = true
    if sim.side == 空:
      real.selling = false          # 暂停卖出，等下次模拟多单平仓
    sim = {side: 反向, P0: p, k: 0}

real_sell(q):
  if p < 持仓均价*(1+min_profit): return   # 利润保护
  if q 或剩余持仓 < 最小下单金额: q = real.qty
  卖出 q；real.qty 归零时结束本轮真实仓位
```

注：默认 `real_step = step` 时，第 1 步和第 2 步会在同一档重复买入，实现时二者只能保留一个触发入口。

## 8. 回测时重点看的指标

- 每轮真实仓位的收益、持有时长、最大浮亏。
- 触及 `real_cap` 的次数，以及触及上限后最终是否盈利退出。
- 资金利用率（平均占用 ÷ `real_cap`）。
- N 取 3%、5%、8%、10%，`first_sell_ratio` 和 `sell_parts` 取不同组合时的对比。
- 按币种和行情阶段（单边上涨、单边下跌、震荡）分别统计。
