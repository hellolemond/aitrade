# BTC 对冲版（H 方案）手动操作指南

> 不写程序，用 TradingView 看信号 + 币安 App 手动下单。以 4,000U 为例。规则依据见[对冲版策略](./趋势通道对冲版策略.md)。非投资建议。

## 一、一次性准备

### 1. 币安账户

| 项目 | 说明 |
|---|---|
| 开通合约 | 需要 **U 本位合约** 和 **币本位合约** 两个账户（App：交易 → 合约，按提示开通并完成测评） |
| 资金分配 | **主仓 2,800U**：放在现货账户<br>**空单仓 1,200U**：划转到 U 本位合约账户（App：资产 → 划转） |
| 默认设置 | U 本位 BTCUSDT 永续、币本位 BTCUSD 永续都设为：**逐仓、1 倍杠杆、单向持仓** |

**永远不要调高杠杆。**

### 2. TradingView 图表与提醒

1. 打开 TradingView，品种选 **BINANCE:BTCUSDT**（现货），周期选 **1D（日线）**。
2. 底部「Pine 编辑器」→ 新建 → 粘贴下面的脚本 → 保存 → 添加到图表：

```pine
//@version=5
indicator("EMA32 趋势通道", overlay = true)
len = input.int(32, "周期")
upper = ta.ema(high, len)
lower = ta.ema(low, len)

var int state = 1
state := state == 1 ? (close < lower ? 0 : 1) : (close > upper ? 1 : 0)
flipUp = state == 1 and state[1] == 0
flipDown = state == 0 and state[1] == 1

plot(upper, "上轨", color.new(color.red, 0), 2)
plot(lower, "下轨", color.new(color.green, 0), 2)
bgcolor(state == 1 ? color.new(color.red, 92) : color.new(color.green, 92))
plotshape(flipUp, "转多", shape.triangleup, location.belowbar, color.red, size = size.small)
plotshape(flipDown, "转空", shape.triangledown, location.abovebar, color.green, size = size.small)

alertcondition(flipUp, "BTC 转多", "BTC 日线转多：执行转多操作")
alertcondition(flipDown, "BTC 转空", "BTC 日线转空：执行转空操作")
```

这和 [hellolemond/t](https://github.com/hellolemond/t) 的趋势通道是同一套规则（原规则就是 Pine 写的）：红色背景 = 多头，绿色背景 = 空头。

3. 建两个提醒（右上角闹钟 → 创建提醒）：
   - 条件：「EMA32 趋势通道」→「BTC 转多」，触发：**每根 K 线收盘一次（Once Per Bar Close）**
   - 条件：「EMA32 趋势通道」→「BTC 转空」，同样选「每根 K 线收盘一次」
   - 通知方式勾选 App 推送 / 邮件

> 不用 TradingView 也可以：每天 08:00 后在任意图表上加两条 EMA（来源分别选「最高价」「最低价」，长度 32），按第三节规则自己判断。

### 3. 记录表

建一个表格（Excel / Numbers / 备忘录均可），每次操作记一行：

| 日期 | 信号 | 收盘价 | 操作 | 账户 | 方向 | 数量 | 成交价 | 手续费 | 操作后：现货 BTC / 主仓 USDT / 币本位空单张数 / U 本位空单数量 / 空单仓 USDT |
|---|---|---|---|---|---|---|---|---|---|

## 二、判断规则

每天**北京时间 08:00 之后**（币安日线收盘），看**刚收盘**的那根日线：

| 当前状态 | 条件 | 结果 |
|---|---|---|
| 多头 | 收盘价 **低于下轨** | 转空 |
| 空头 | 收盘价 **高于上轨** | 转多 |
| 其他 | — | 保持，不操作 |

- **只看收盘价**，盘中穿过通道不算。
- 收到 TradingView 提醒后执行即可，没有提醒的日子什么都不做。
- 成交时间：08:00 之后尽快，当天内完成都可以（回测按次日开盘价成交，晚几小时影响很小）。

## 三、操作步骤

### A. 初始建仓（只做一次）

先看当前状态（TradingView 背景颜色或最新的三角标记）。

**当前是多头：**

1. 现货：用主仓 2,800U **买入 BTC**。
2. 把买到的 BTC **划转到币本位合约账户**（之后一直放在那里）。
3. 空单仓 1,200U 留在 U 本位账户，不操作。

**当前是空头（2026-10-29 时为空头）：**

1. 主仓 2,800U **继续持有 USDT**，不买。
2. U 本位 BTCUSDT 永续，**逐仓 1 倍，开空**：
   - 数量 = 1,200 ÷ 当前价格，**向下取整到 0.001 BTC**
   - 例：价格 80,000 → 1,200 ÷ 80,000 = 0.015 → 开 **0.015 BTC**
   - 若下单提示保证金不足，减少 0.001 再试
3. 检查：强平价应在开仓价 **上方约 95%** 以上（约 2 倍开仓价）。

### B. 转多（收盘价高于上轨）

| 顺序 | 账户 | 操作 |
|---|---|---|
| 1 | 币本位 | 如果有 BTCUSD 空单：**全部平仓**（买入平空）。盈亏自动以 BTC 结算，BTC 留在币本位账户 |
| 2 | 现货 | 如果主仓还有 USDT：**全部买入 BTC**，再划转到币本位账户 |
| 3 | U 本位 | 如果有 BTCUSDT 空单：**全部平仓**。之后空单仓持有 USDT |

完成后：主仓 = 全部是 BTC（在币本位账户）；空单仓 = 全部是 USDT。

### C. 转空（收盘价低于下轨）

| 顺序 | 账户 | 操作 | 数量怎么算 |
|---|---|---|---|
| 1 | 币本位 | BTCUSD 永续，逐仓 1 倍，**开空** | 张数 = 币本位账户里的 BTC 数量 × 当前价格 ÷ 100，**向下取整** |
| 2 | U 本位 | BTCUSDT 永续，逐仓 1 倍，**开空** | 数量 = U 本位账户 USDT ÷ 当前价格，**向下取整到 0.001** |

**例**：币本位有 0.035 BTC，空单仓 1,200U，价格 81,000：

- 币本位：0.035 × 81,000 ÷ 100 = 28.35 → 开空 **28 张**
- U 本位：1,200 ÷ 81,000 = 0.0148 → 开空 **0.014 BTC**

注意：

- **现货 BTC 不卖**。币本位空单把它的价值锁住，跌多少空单就赚多少。
- 每次都按**当时实际的余额**计算，不要照抄上次的数量。
- 开完检查：币本位空单基本不会强平；U 本位空单强平价应约为开仓价的 2 倍。

### D. 年度再平衡（每年 1 月 1 日 08:00 后）

**1. 算两部分价值**（用当前价格）：

```
主仓 = 币本位账户权益（BTC 数量 × 价格，已含空单盈亏） + 现货里属于主仓的 USDT
空单仓 = U 本位账户权益（钱包余额 + 未实现盈亏）
总值 = 主仓 + 空单仓
主仓目标 = 总值 × 70%
差额 = 主仓目标 − 主仓
```

差额小于总值的 1%：今年不调整。

**2. 主仓多了（差额 < 0），需要给空单仓 |差额|：**

1. U 本位有空单的话先平仓。
2. 主仓有 USDT 先用 USDT；不够时把相应数量的 BTC 从币本位划回现货，**卖出**（币本位有空单的话先平仓）。
3. 把 |差额| 的 USDT 划转到 U 本位账户。
4. 当前是空头的话：按 C 的公式**重新开**币本位空单和 U 本位空单。

**3. 空单仓多了（差额 > 0），需要给主仓 差额：**

1. U 本位有空单的话先平仓。
2. 从 U 本位划出 差额 USDT 到现货。
3. 当前是多头：用这些 USDT 买入 BTC，划到币本位账户；当前是空头：USDT 先留着，转多时一起买。
4. 当前是空头的话：按 C 的公式用剩余 USDT **重新开** U 本位空单。

## 四、日常检查（每周一次，几分钟）

| 检查 | 正常范围 |
|---|---|
| 币本位空单张数 × 100 | ≈ 币本位 BTC × 价格（偏差小于 100 美元） |
| U 本位空单强平价 | ≥ 开仓价的 1.9 倍 |
| U 本位空单浮亏 | 超过保证金的 40% 时人工检查（历史最坏约 27%） |
| 杠杆 | 两个合约都是 1 倍 |
| 资金费 | 空单通常收到小额资金费，偶尔支付，属正常 |

---

## 五、不要做的事

1. **不加杠杆**，不用全仓模式放大仓位。
2. **不在盘中操作**，不因为新闻、涨跌提前开平仓。
3. **不设额外止损**。平仓条件只有「收盘价越过通道」。
4. **不在亏损后改规则**。胜率只有三成多，连亏 5~7 次在历史上出现过。
5. **不把币本位账户里的 BTC 转走**，它是空单的保证金。
6. **不用于山寨币**。H 方案只适用于 BTC、ETH。

## 六、常见问题

**Q：错过了 08:00 怎么办？**
当天任何时候补做都可以；隔了几天也按「当前状态」补齐仓位即可。

**Q：转多后第二天又转空（来回打脸）？**
照做。这是策略的固有成本，回测已包含。

**Q：没收到 TradingView 提醒？**
每天 08:00 后自己看一眼背景颜色是否变化即可；提醒只是辅助。

**Q：币本位空单为什么亏了但账户没少？**
空单亏损的同时现货 BTC 涨了，两者抵消。看账户总权益（美元价值），不要只看空单盈亏。

**Q：资金增加怎么办？**
在年度再平衡时一并加入，按 70:30 分配；或在下一次转多/转空操作时按比例加入。

## 七、一页速查

```
每天 08:00 后看 BTC 日线（或等 TradingView 提醒）
│
├─ 空头 → 收盘 > 上轨 → 转多
│     ① 币本位：平掉 BTCUSD 空单
│     ② 现货：主仓 USDT 全部买 BTC → 划到币本位
│     ③ U 本位：平掉 BTCUSDT 空单
│
├─ 多头 → 收盘 < 下轨 → 转空
│     ① 币本位：开空  张数 = BTC × 价格 ÷ 100（向下取整）
│     ② U 本位：开空  数量 = USDT ÷ 价格（向下取整到 0.001）
│
└─ 其他 → 不动

每年 1 月 1 日：主仓 : 空单仓 拉回 70 : 30
所有合约：逐仓、1 倍、单向持仓
```
